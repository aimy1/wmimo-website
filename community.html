关于 Wmimo 与开源支持

关于 Wmimo · 纯粹、现代、自由开源

基于 Flutter 与 Mihomo 核心深度构建，秉承 100% 自由开源、零商业广告与全功能永久免费。追求工程极致与极简视觉，为每一位用户带来纯净流畅的下一代跨平台网络体验。

Core Principles

初心与核心支柱

坚持不妥协的工程品味，守候开源世界的纯粹与温度

🛡️

100% 自由开源 · GPL-3.0

所有客户端源码、协议对接与构建脚本完全公开透明。在 GNU GPL-3.0 协议保障下，杜绝任何闭源私货、后门与恶意篡改，永久保障用户的软件自由。

🍃

零商业广告 · 尊重隐私

不内嵌任何广告推送、不搜集追踪设备隐私、不记录用户访问日志。没有弹窗打扰，没有付费锁区与套路，还原网络工具本该有的纯粹克制。

⚡

现代化工程美学

摆脱传统代理客户端陈旧厚重的刻板印象。采用 Flutter 原生丝滑渲染与响应式卡片体系，结合轻量系统托盘与全局快捷键，带来行云流水的使用感受。

🌍

全平台一致互通

深度适配 Windows、Linux 与 Android。统一的内核调度、一致的配置语法与分流表现，无论在桌面工作站还是移动设备，体验无缝衔接。

Architecture & Foundations

开源基石与致敬

Wmimo 站在巨人的肩膀上前行，向所有推动开放网络技术的先驱致敬

CORE KERNEL

🚀 MetaCubeX (Mihomo)

行业领先的下一代通用代理核心。提供原生 TUN 虚拟网卡、Fake-IP 防污染、进程分流嗅探以及新一代高速传输协议（Hysteria 2、TUIC v5、VLESS Reality）。

UI FRAMEWORK

💙 Flutter & Dart

Google 开源的现代化多平台 UI 开发套件。赋予 Wmimo 60/120 FPS 丝滑动画响应、原生桌面嵌入能力以及高效易维护的声明式界面逻辑。

OPEN SOURCE SPIRIT

🌟 GooRingX & 社区贡献

由衷感谢 GooRingX (vowe) 杰出的开源探索与宝贵灵感。Wmimo 严格遵循 GPL-3.0 协议规范，并将持续回馈开源社区与文档生态。
