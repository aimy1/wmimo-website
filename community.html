关于 Wmimo 与开源支持

关于 Wmimo · 纯粹、现代、自由开源

基于 Flutter 与 Mihomo 核心构建的跨平台代理客户端，遵循 GPL-3.0 协议开源，无商业广告与遥测追踪，全功能免费开放给五大桌面与移动平台。

Core Principles

初心与核心支柱

代码透明、尊重隐私、交互克制、全平台原生适配

🛡️

100% 自由开源 · GPL-3.0

所有客户端源码、协议对接与构建脚本完全公开透明。在 GNU GPL-3.0 协议保障下，杜绝任何闭源私货、后门与恶意篡改，永久保障用户的软件自由。

🍃

零商业广告 · 尊重隐私

不内置任何广告推送，不收集设备遥测数据，也不记录用户的访问与分流日志。没有弹窗催促或收费门槛，专注提供稳定纯粹的代理体验。

⚡

现代化工程美学

告别信息堆砌与老旧布局。基于 Flutter 原生渲染打造清晰的微卡片层级，配合轻量系统托盘与全局模式联动，高频操作顺手直观。

🌍

全平台一致互通

全面适配 Windows、macOS、Linux、Android 与 iOS 五大平台。统一的内核调度、一致的配置语法与分流表现，在桌面与移动设备间无缝切换。

Architecture & Foundations

开源基石与致敬

基于成熟的开源基础设施构建，向推动开放网络与跨平台工具发展的先驱致敬

CORE KERNEL

🚀 MetaCubeX (Mihomo)

行业领先的下一代通用代理核心。提供原生 TUN 虚拟网卡、Fake-IP 防污染、进程分流嗅探以及新一代高速传输协议（Hysteria 2、TUIC v5、VLESS Reality）。

UI FRAMEWORK

💙 Flutter & Dart

Google 开源的多平台 UI 框架，为 Wmimo 提供高帧率原生渲染、跨桌面与移动端的统一交互组件以及易维护的声明式工程结构。

OPEN SOURCE SPIRIT

🌟 GooRingX & 社区贡献

由衷感谢 GooRingX (vowe) 杰出的开源探索与宝贵灵感。Wmimo 严格遵循 GPL-3.0 协议规范，并将持续回馈开源社区与文档生态。
