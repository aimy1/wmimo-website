INSTALLATION & PERMISSIONS

🛠️ 安装与权限快速命令

macOS 首次运行如遇 Gatekeeper 拦截（移除隔离属性）：
sudo xattr -rd com.apple.quarantine /Applications/Wmimo.app
Linux 赋予 AppImage 执行权限并直接启动：
chmod +x Wmimo-Linux-*.AppImage && ./Wmimo-Linux-*.AppImage
SECURITY & INTEGRITY

🔒 软件包 SHA-256 校验说明

每个安装包卡片均提供官方 SHA-256 哈希值一键复制。您可在终端执行以下指令核对本地文件指纹：

Windows PowerShell:
Get-FileHash .\Wmimo-* -Algorithm SHA256
macOS / Linux Terminal:
shasum -a 256 Wmimo-*
