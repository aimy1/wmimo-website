## 🎯 各平台客户端选型推荐

- **Windows 用户**：
  - 推荐 **Wmimo**（基于 Flutter + Mihomo 核心，18px 现代化微卡片设计，支持 TUN 虚拟网卡与全功能托盘）；
  - 或 [FlClash](https://github.com/chen08209/FlClash/releases)、[Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev/releases)。
- **Linux 用户**：
  - 推荐 **Wmimo**（提供 AppImage, Deb, RPM, Arch 多发行版原生打包）；
  - 或 [FlClash](https://github.com/chen08209/FlClash/releases)。
- **Android 用户**：
  - 推荐 **Wmimo**（Flutter 打造，内存开销极低且原生支持深浅双主题）；
  - 或 [Clash Meta for Android](https://github.com/MetaCubeX/ClashMetaForAndroid/releases)。
- **iOS 用户**：
  - 推荐 [Shadowrocket](https://apps.apple.com/us/app/shadowrocket/id932747118)（小火箭）或 [Surge for iOS](https://apps.apple.com/us/app/surge-5/id1442620678)。
- **路由器 / 进阶部署**：
  - 推荐 [OpenClash](https://github.com/vernesong/OpenClash) 或 [PassWall2](https://github.com/xiaorouji/openwrt-passwall)。
