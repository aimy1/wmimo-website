常见问题排查 (FAQ)

收集了用户在使用 Wmimo 过程中最常见的问题与解决方案。

📄 查看 .md 源码

1. 导入订阅时提示连接超时？

• 检查订阅链接是否能够通过本地浏览器直接下载；
• 确认当前运营商 DNS 是否能够解析订阅服务器域名；
• 可尝试在设置中配置自定义 DNS（如 223.5.5.5 / 119.29.29.29）后重试。

2. 开启 TUN 模式后无法打开网页？

• 检查是否与其他 VPN 或虚拟网卡工具（如其他代理客户端）同时运行产生了路由冲突；
• 退出其他代理工具，在 Wmimo 中关闭 TUN 并重新开启一次；
• 检查防火墙是否拦截了 wmimo-core 进程的网络出站请求。

3. Linux AppImage 无法在 Ubuntu 24.04 运行？

Ubuntu 24.04 默认不再附带旧版 libfuse2 库。通过终端安装即可正常运行：

Bash 
sudo apt update && sudo apt install libfuse2 -y

4. 订阅更新后节点没有刷新？

进入 “配置管理”，点击对应订阅配置右侧的刷新图标手动触发一次全量拉取。
