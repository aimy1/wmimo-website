外部控制器与 Web 仪表盘 (Dashboard) 对接

开放 RESTful API，对接 MetaCubeXD、YACD 与 Zashboard 实现实时连接追踪与监控。

⚙️ 开启 External Controller

external-controller: 127.0.0.1:9090     # 控制器监听地址
secret: "your_password_here"            # 访问密钥授权

🖥️ 推荐主流 Web 仪表盘

  • MetaCubeXD（官方推荐）：https://metacubex.github.io/metacubexd/ - 深度支持 Mihomo 特性。
  • YACD Dashboard：https://yacd.haishan.me/ - 经典易用。
  • Zashboard：https://zashboard.pages.dev/ - 极简现代化毛玻璃界面。
