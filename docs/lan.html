局域网共享与 Switch / PS5 / 智能电视代理指南

将运行 Wmimo 的电脑或手机作为局域网代理网关，免客户端为家庭多设备加速。

📄 查看 .md 源码

🚀 步骤一：开启局域网共享

mixed-port: 7890       # 混合代理端口
allow-lan: true        # 允许局域网设备接入
bind-address: "*"      # 监听所有网卡

🎮 步骤二：主机与电视配置代理

  • Nintendo Switch：进入「互联网设置」-> 选择当前 WiFi ->「更改设置」-> 启用「代理服务器」，输入运行 Wmimo 电脑的 IP 与端口 7890；
  • PS5 / Xbox：进入「网络设定」->「进阶设定」->「Proxy 服务器」，填入 IP 与端口 7890；
  • Apple TV / 智能电视：在 WiFi 详细信息中配置 HTTP 代理为「手动」。
