从源码本地编译构建

本文档指导开发者配置本地开发环境并从源码编译 Wmimo 各平台客户端产物。

📄 查看 .md 源码

🛠️ 环境要求

  • Flutter SDK: >= 3.35.0
  • Dart SDK: >= 3.12.2
  • Windows: Visual Studio 2022 C++ 桌面开发工作负载
  • Linux: gtk3, clang, cmake, ninja-build

⚡ 快速开始

Terminal 
# 1. 克隆代码仓库
git clone https://github.com/aimy1/Wmimo.git
cd Wmimo

# 2. 安装依赖并生成国际化多语言代码
flutter pub get
dart run slang

# 3. 下载对应平台的 Mihomo 内核文件
dart run tool/download_all_cores.dart

# 4. 本地调试运行
flutter run

📦 编译 Release 版本

针对不同目标平台，运行对应构建命令：

Terminal 
# Windows Release (生成 x64 安装程序与便携包)
flutter build windows --release

# Linux Release (一键打包 Deb, RPM, AppImage, Arch 与 Tarball)
flutter build linux --release
bash tool/package_linux.sh v1.0.33

# Android Release (生成 APK 安装包)
flutter build apk --release
