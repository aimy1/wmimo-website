新一代网络协议与 Full Cone NAT 指南

详解 Hysteria 2、TUIC v5、VLESS Reality 协议优势及游戏全锥型 NAT 优化。

📄 查看 .md 源码

⚡ 新一代协议横向对比

协议名称 传输机制 核心优势 最佳场景
Hysteria 2 基于 UDP (QUIC Brutal) 突破 TCP 丢包退避限制，自动拥塞感知，晚高峰带宽压榨 跨国高丢包、恶劣弱网、大文件高速下载
TUIC v5 基于 UDP (0-RTT QUIC) 握手延迟极低，连接复用性能优异 移动端多基站频繁切换、网页高频冲浪
VLESS Reality 基于 TCP/TLS 消除自签名证书特征，直接借用目标权威站点 TLS 证书 严苛封锁环境、长期稳定办公

🎮 Full Cone NAT（全锥型 NAT）游戏联机优化

在开启 Wmimo 的 TUN 虚拟网卡模式进行外服主机与 PC 联机游戏时，NAT 类型直接决定了能否顺利与队友建立 P2P 直连。

为什么需要 Full Cone NAT？ 普通的对称型 NAT（Symmetric NAT / Type D）会为每个连接分配不同的公网端口，导致游戏内无法直连。开启 endpoint-independent-nat: true 后，公网映射端口保持恒定，游戏内 NAT 类型可自动提升至 Open (Type A)。 
tun:
  enable: true
  stack: system
  endpoint-independent-nat: true  # 启用全锥型 NAT 穿透
  auto-route: true
