# 快速上手指南

只需 3 步，即可在 1 分钟内完成 Wmimo 的配置并开启网络代理。

---

## 🚀 3 步快速配置流程

### 步骤 1：下载并安装客户端
前往 [下载中心](../download.html) 获取适配您操作系统的最新安装包：
- **Windows**：标准安装包 `.exe` 或绿色便携包 `.zip`；
- **Linux**：通用独立镜像 `.AppImage`、Debian/Ubuntu `.deb`、Fedora `.rpm`、Arch `.pkg.tar.zst`；
- **Android**：通用 APK 或 ARM64 APK。

### 步骤 2：导入订阅配置
打开 Wmimo，在左侧边栏进入 **“配置管理”**：
1. 点击右上角加号 `+`；
2. 选择 **“从 URL 导入”**；
3. 粘贴您的订阅地址并点击保存。

### 步骤 3：选择节点并开启代理
1. 在左侧进入 **“代理节点 (Proxy)”** 列表中选择心仪的节点；
2. 回到 **“概览 (Overview)”** 页面，开启右上角主开关或开启 **“System Proxy”** 即可。

---

## 📥 支持的配置导入方式

- **URL 订阅导入**：支持标准 Clash / Mihomo 订阅链接，支持设置后台定时自动刷新；
- **二维码扫描**：支持摄像头扫描二维码或从剪贴板图片识别；
- **本地文件导入**：直接导入本地已有的 `.yaml` 配置文件；
- **配置补丁 (Profile Patch)**：在不改动原订阅的前提下追加自定义分流规则与 DNS 策略。
