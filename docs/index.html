快速上手指南

只需 3 步，即可在 1 分钟内完成 Wmimo 的配置并畅享极速网络体验。

🚀 3 步快速配置流程

1

下载并安装客户端

前往 下载中心 获取适配您操作系统的最新安装包（Windows 安装包 `.exe` / Linux `.AppImage` / Android APK）。

2

导入订阅配置

打开 Wmimo 侧边栏进入 “配置管理”，点击右上角加号 +，选择 “从 URL 导入” 并粘贴您的订阅链接。

3

选择节点并开启代理

在 “代理节点” 列表中选择心仪的节点，回到仪表盘点击 “启动代理” 或开启系统代理即可。

📥 支持的配置导入方式

  • URL 订阅导入：支持标准的 Clash / Mihomo 订阅链接，支持设置后台定时自动刷新；
  • 二维码扫描：支持摄像头扫描二维码或从剪贴板图片识别；
  • 本地文件导入：直接导入本地已有的 .yaml 配置文件；
  • 配置补丁 (Profile Patch)：在不改动原订阅的前提下，追加自定义的分流规则与 DNS 策略。
