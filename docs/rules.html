高级路由规则与进程级分流配置指南

掌握 Mihomo 规则语法，实现针对游戏、通讯软件与域名的精准出站分流。

📄 查看 .md 源码

🎯 规则匹配原则

  • 自上而下匹配：一旦某一条规则命中，核心立即将流量分配到指定策略组并停止向下匹配；
  • 兜底策略 (MATCH)：写在规则列表最底部，捕获所有未被前方显式规则捕获的剩余流量。

🎮 实战：针对应用进程名称分流 (PROCESS-NAME)

无需搜集应用复杂的 CDN 域名或 IP 段，直接按桌面可执行程序名称（.exe / Linux 进程名）精准分流： 

rules:
  # 游戏客户端直连或走专属低延迟游戏节点
  - PROCESS-NAME,steam.exe,DIRECT
  - PROCESS-NAME,steamwebhelper.exe,DIRECT
  - PROCESS-NAME,epicgameslauncher.exe,DIRECT

  # 通讯与生产力软件走特定代理组
  - PROCESS-NAME,telegram.exe,TelegramGroup
  - PROCESS-NAME,Telegram.exe,TelegramGroup

  # 国内服务与局域网直连
  - GEOIP,private,DIRECT,no-resolve
  - GEOSITE,cn,DIRECT
  - GEOIP,CN,DIRECT

  # 最终兜底走默认代理
  - MATCH,Proxy

🧩 常用规则类型速查

规则关键字 语法示例 说明
DOMAIN-SUFFIX DOMAIN-SUFFIX,google.com,Proxy 匹配主域名及其所有二级、三级子域名。
DOMAIN-KEYWORD DOMAIN-KEYWORD,github,Proxy 只要域名包含该关键字即命中。
GEOSITE GEOSITE,bilibili,DIRECT 基于 GeoSite 预打包域名列表。
GEOIP GEOIP,CN,DIRECT 根据目标 IP 地理归属分流。
AND / OR / NOT AND,((GEOIP,CN),(DST-PORT,443)),DIRECT 多条件复合逻辑运算。
