订阅管理与远程规则集 (Providers)

深入掌握 Proxy Providers 节点集合并、Rule Providers 远程规则订阅、自动更新策略与 Geo 数据库维护。

💡 什么是 Provider？ Provider（提供者）是 Mihomo / Clash 核心中用于实现配置模块化与解耦的强大特性。通过 Provider，您可以将节点列表与分流规则托管在外部远程链接或独立本地文件中，实现多订阅动态合并与无人值守静默自动更新。

📦 1. 代理集合 (Proxy Providers)

Proxy Providers 允许从一个或多个机场订阅链接动态拉取节点，并自动进行本地缓存与健康检查。策略组可以直接引用 Provider 包含的全部节点：

config.yaml 
proxy-providers:
  Airport-A:
    type: http
    url: "https://example.com/api/v1/client/subscribe?token=xxx"
    path: ./profiles/proxies/airport-a.yaml
    interval: 86400              # 自动更新间隔（秒），86400 为 24 小时
    proxy: DIRECT                # 拉取订阅时使用的出站代理
    filter: "(?i)香港|日本|新加坡" # 正则过滤：仅保留匹配国家/地区的节点
    exclude-filter: "(?i)官网|剩余|流量"
    health-check:
      enable: true
      url: https://www.gstatic.com/generate_204
      interval: 300              # 健康检查测速周期（秒）
      timeout: 5000
      lazy: true                 # 仅在策略组被使用时触发测速，节省流量与并发

  Airport-B:
    type: file
    path: ./profiles/proxies/custom-nodes.yaml
    health-check:
      enable: true
      url: https://cp.cloudflare.com/generate_204
      interval: 600

🛡️ 2. 远程分流规则集 (Rule Providers)

Rule Providers 让你无需在主配置文件中手写成千上万行规则，而是直接订阅由社区（如 Loyalsoldier、MetaCubeX 等）每日维护的高精度分流集：

config.yaml 
rule-providers:
  # 1. 规则集：OpenAI / ChatGPT / Claude (Domain 格式)
  ai-services:
    type: http
    behavior: domain             # 支持 domain / ipcidr / classical
    format: yaml                 # 支持 yaml / text / mrs (Mihomo 专属二进制加速格式)
    url: "https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/meta/geo/geosite/openai.yaml"
    path: ./rules/openai.yaml
    interval: 86400

  # 2. 规则集：国内直连域名 (Classical 格式)
  direct-domains:
    type: http
    behavior: domain
    format: text
    url: "https://raw.githubusercontent.com/Loyalsoldier/clash-rules/release/direct.txt"
    path: ./rules/direct.txt
    interval: 86400

  # 3. 规则集：电报 Telegram IP 段 (IP-CIDR 格式)
  telegram-cidr:
    type: http
    behavior: ipcidr
    format: yaml
    url: "https://raw.githubusercontent.com/MetaCubeX/meta-rules-dat/meta/geo/geoip/telegram.yaml"
    path: ./rules/telegram.yaml
    interval: 86400

🔗 3. 在 Rules 中引用 Provider 规则

在 rules: 段中使用 RULE-SET 指令引用已定义的 Rule Provider：

config.yaml 
rules:
  - RULE-SET,ai-services,🤖 AI服务策略组
  - RULE-SET,direct-domains,DIRECT
  - RULE-SET,telegram-cidr,✈️ Telegram策略组,no-resolve
  - GEOIP,CN,DIRECT
  - MATCH,🐟 兜底漏网之鱼

🌍 4. GeoIP 与 GeoSite 数据库自动更新

Mihomo 内核支持直接通过配置开启 Geo 数据库的定时静默拉取与更新，确保国内外 IP 和顶级域识别始终处于最新状态：

config.yaml 
# Geo 数据加载与更新配置
geodata-mode: true               # 启用高性能内存 Geo 索引模式
geo-auto-update: true            # 开启定时自动更新
geo-update-interval: 48          # 更新周期（小时）

geox-url:
  geoip: "https://testingcf.jsdelivr.net/gh/MetaCubeX/meta-rules-dat@release/geoip.dat"
  geosite: "https://testingcf.jsdelivr.net/gh/MetaCubeX/meta-rules-dat@release/geosite.dat"
  mmdb: "https://testingcf.jsdelivr.net/gh/MetaCubeX/meta-rules-dat@release/country.mmdb"
