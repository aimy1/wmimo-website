🎯 各平台客户端选型推荐

  • Windows 用户：推荐 Wmimo（基于 Flutter + Mihomo 核心，18px 现代化微卡片设计，支持 TUN 虚拟网卡与全功能托盘）或 FlClash。
  • Linux 用户：推荐 Wmimo（提供 AppImage, Deb, RPM, Arch 多发行版原生打包支持）。
  • Android 用户：推荐 Wmimo（Flutter 跨平台原生架构，内存开销低）或 Clash Meta for Android。
  • iOS 用户：推荐 Shadowrocket 或 Surge for iOS。
