# 出站与分流模式详解

了解 Wmimo 的三种核心出站模式以及如何根据需求灵活切换。

---

## ⚙️ 三大出站模式对比

| 模式名称 | 工作机制 | 适用场景 |
| :--- | :--- | :--- |
| **规则分流 (Rule)** | 根据内置规则库智能分流：国内域名/IP 直连，海外请求经由代理转发 | 日常主力使用（强烈推荐） |
| **全局代理 (Global)** | 所有非局域网流量均强制通过用户选定的单一节点发出 | 特定海外网络调试或排障 |
| **直接连接 (Direct)** | 所有流量直接走本地物理网卡发出，不经由任何代理服务器 | 访问纯国内服务或临时停用代理 |

---

## ⚡ 节点测速与智能选路

在 **“代理节点 (Proxy)”** 列表中，点击右上角 **“一键测速”** 按钮可对当前策略组内的所有节点进行并发延迟测试：

- 🟢 **绿色标签 (< 80ms)**：低延迟优质节点；
- 🟡 **黄色标签 (80ms ~ 180ms)**：中等延迟正常节点；
- 🔴 **红色标签 (> 180ms 或 Timeout)**：高延迟或不可用节点。
